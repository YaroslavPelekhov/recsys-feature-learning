# Исходник статьи

Компилятор **XeLaTeX**. Загрузите в Overleaf весь архив, выберите `article.tex` основным файлом. Локально выполните `xelatex article.tex` дважды из этой папки.

- `article.tex` — текст, формулы, таблицы и встроенная библиография.
- `figures/*.pdf` — векторные рисунки для LaTeX; SVG оставлены для редактирования.
- `references.bib` — те же источники в формате для библиографических менеджеров; BibTeX для сборки не требуется.

Числа в отмеченных `GENERATED` блоках и графики обновляются из проверенных результатов командой `uv run --locked python scripts/write_paper.py` в полном репозитории. Эта команда сохраняет текст статьи. Исходные данные и обучение для пересборки документа не нужны.
