# Исследовательский вклад и границы новизны

Работа не объявляет NCE, EASE, conditional negative sampling, Bayes correction или арифметическое смешивание распределений новыми принципами. Её вклад - воспроизводимое исследование конкретных механизмов переноса признаков в рекомендательную задачу.

| Компонент | Основа в литературе | Собственная проверяемая часть | Свидетельство |
| --- | --- | --- | --- |
| Автоматический выбор окон | Feature search, временные агрегаты | Ограниченная грамматика kernels, два user-sample seed, полная публикация поиска и отсутствия устойчивого выигрыша | reports/main, reports/replication |
| Temporal EASE + GBDT | EASE, временные профили | Шесть learned scores, равные candidates, отдельный контроль расширения retrieval, новая внешняя когорта и ретроспективный период | reports/v2 |
| Условный transition critic | Logistic density-ratio learning, перестановочные null models | User-day endpoint permutation с сохранением margins, matched global/conditional encoders и sparse signed graph, point-in-time downstream-признаки | reports/v3 |
| Поддержка noise | Стандартное свойство смеси распределений | Вывод конкретного expected null, измерение holes на реальных данных, отрицательный результат заранее замороженной mixture-коррекции | reports/v3_support |
| Соответствие агрегации задаче | PMI/SGNS, product/mixture of experts | Формальный разбор среднего embeddings, конструктивный пример расхождения решений и факторная схема G0/G1/A0/A1 с общей поддержкой | src/rec/reconstruction.py, docs/RESEARCH_V4_PROTOCOL.md |
| Перенос реконструкции | Cross-cohort validation | Новые 1000 UID с полными историями (5.2M событий), отдельная заморозка 20 fusion trials, единственное primary A1-G0, все secondary contrasts | reports/v4 |
| Проверяемость вывода | Reproducible ML, временная оценка | Полные знаменатели, отсутствие positive injection, predictions-before-targets, replay, изменение будущих строк и проверка компактных артефактов | rec verify, tests |

## Что именно можно утверждать

Самостоятельно спроектированы экспериментальная конструкция, её реализация, согласование downstream-сигнала с доступной историей и контролируемое сравнение механизмов. Известные формулы выведены для нашего дизайна, а не представлены как новые общие теоремы. Отрицательные результаты и противоречащие гипотезе исходы сохраняются.

Высокий training AUC не выдаётся за обобщение. Аудит на более поздних переходах прежнего search - механистическая диагностика, не новая внешняя проверка. Новая user-когорта не называется независимым будущим периодом. Успех вторичного A0 не заменяет заранее основной A1 и не означает победу над ручным CatBoost.

## Что работа не устанавливает

Мировой приоритет комбинации; превосходство над всеми современными последовательными моделями; причинный эффект рекомендаций; прирост online CTR/выручки; эквивалентность моделей из-за CI, содержащего ноль; перенос на миллиарды событий; качество discovery из общего NDCG, полученного преимущественно на повторах. Для этих утверждений имеющихся экспериментов недостаточно.
