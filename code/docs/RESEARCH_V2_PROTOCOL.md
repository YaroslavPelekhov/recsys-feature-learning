# Второй этап: обученные связи и остаточная временная маршрутизация

Первый эксперимент не подтвердил пользу перебора соседних окон. Новый этап меняет представление связей, проверяет расширение retrieval и обучаемую коррекцию сильного бустинга. Старые августовские test-результаты открыты: все новые августовские сравнения считаются exploratory.

## Литературная опора и граница новизны

- [EASE, Steck 2019](https://arxiv.org/abs/1905.03375): обучаемая плотная item–item матрица с нулевой диагональю и замкнутым решением. Это известный baseline, не наш новый алгоритм.
- [LightGCN, He et al. 2020](https://arxiv.org/abs/2002.02126): представления на user–item графе; мотивирует сравнение с обученными связями вместо ручных агрегатов. Полная репликация LightGCN на этом этапе не заявляется.
- [FEASE, 2025](https://arxiv.org/abs/2504.02288): использование побочных признаков в shallow autoencoder уже исследовано; добавление метаданных к EASE само по себе не является новизной.
- [MARS, июнь 2026](https://arxiv.org/abs/2606.03718) и [MARS, октябрь 2026](https://arxiv.org/abs/2610.07505): многомасштабные временные представления и адаптивная маршрутизация уже известны. Эти препринты — мотивация, не независимо воспроизведённые результаты.

Исследовательская конструкция здесь — небольшой residual router над временными EASE-экспертами, который обучается исправлять замороженный GBDT по его out-of-time прогнозам. Это проверяемая комбинация с собственными абляциями, без заявления о доказанном мировом приоритете. Её смысл: автоматическое представление должно объяснять остаток сильного baseline, а не просто повторять популярность.

## Данные и кандидаты

Сохраняется вся исходная история выбранных пользователей; duration/percentage KION исключены. Все модели используют одинаковую историю строго до cutoff и одинаковые метаданные.

Дополнительные признаки: EASE с lambda 100/1000, профили all / half-life 7 / half-life 30 дней — шесть оценок. Отдельный кандидатный источник — top-120 EASE(lambda=1000, half-life=30), объединённый с исходным RRF top-120. Итоговое объединение до 240 объектов общее для всех сравниваемых методов. Ручные retrieval-признаки вычислены исходными тремя источниками и не включают EASE-score. Польза расширения кандидатов отделяется от пользы нового ranker.

В development разрешено вычислять независимые от состава batch рекомендации только для пользователей с измеримой будущей целью, экономя время. Генератор принимает query IDs, но не labels/target items; item statistics и граф обучаются по всей прошлой истории. Инвариант подмножества queries проверяется тестом.

## Методы и выбор

Ручной CatBoost, EASE standalone, CatBoost + шесть EASE-признаков, глобальная смесь, персональный router и residual router. Router использует query-normalized scores; контекст — исторические объём/давность/скорость активности и разногласие экспертов. Он обучается listwise cross-entropy с регуляризацией. Для residual-варианта baseline-score на обучающих запросах получается только моделью, обученной на более ранних срезах. Первый срез служит начальным обучением teacher, не обучает residual router.

Глубины CatBoost 5/7, до 600 деревьев, checkpoint 25; общий бюджет baseline и hybrid. Router: L2 0,01/0,1; residual scale 0,25/0,5/1; одна и та же заранее заданная грамматика экспертов. Настройка выполняется на августовском search, confirm остаётся диагностикой. Primary variant выбирается по search и фиксируется до нового внешнего теста. Все пробы, включая неудачные, сохраняются.

## Новый внешний тест

До нового подбора резервируется 10 000 пользователей с seed 314159 из пользователей, не входивших в выборки 2026/2027. ID фиксируются отдельно. **Новые тестовые метки: 21–27 июня 2021, exclusive end 28 июня.** На этом периоде ранее не считались метрики и не обучались supervised-модели.

Для внешней проверки модели переобучаются с нуля: начальный teacher-срез 17–23 мая, затем обучающие метки 24–30 мая, 31 мая–6 июня, 7–13 июня и 14–20 июня. Supervised-метки — только пользователей development-выборки 2026. История внешних пользователей до каждого cutoff доступна всем методам как неразмеченная история, что соответствует warm-user персонализации. Метки внешних пользователей не используются при обучении/настройке. Перед 21 июня будущие записи скрыты целиком.

Гиперпараметры выбираются на августовском development и замораживаются до расчёта июньской внешней метрики. Это ретроспективный внешний период плюс новые пользователи, не симуляция разработки алгоритма до наступления июня. Его сильная сторона — новые supervised targets; ограничение — тот же сервис и статические метаданные.

Основное сравнение — замороженный выбранный метод против manual на одних кандидатах, средние отдельных model seeds 17/42/73 и парный user bootstrap (3 000 resamples). Дополнительные методы — описательные абляции. IDCG/Recall учитывают unretrieved/cold positives. После открытия внешнего test подбор по нему не продолжается; дальнейшие изменения требуют нового holdout.
