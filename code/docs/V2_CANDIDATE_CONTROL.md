# Дополнительный контроль размера кандидатов

Этот контроль записан до расчёта внешних метрик второго этапа, после заморозки основного рецепта. Он не выбирает primary и не меняет основной протокол/гиперпараметры.

Из общего union восстанавливается исходный RRF top-120. Manual и hybrid повторно обучаются на этом пуле с теми же соответствующими гиперпараметрами и только seed 17. Их внешние predictions сохраняются до построения внешних targets. Основные методы оцениваются на union до 240.

Сопоставление old-pool и union при seed 17 показывает чувствительность к candidate policy. Это вторичный описательный контроль с совпадающими параметрами, не независимый подбор оптимального baseline под old-pool. Между двумя policy отличаются доступные кандидаты; основное fair-сравнение hybrid/manual остаётся внутри одного union. Алгоритм восстановления original pool проверен тестом.
