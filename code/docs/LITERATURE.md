# Литературная карта и решения второго этапа

Поиск и чтение первичных источников: 17 октября 2026. Ниже отделены опубликованные методы, наша реализация и проверяемые предположения. Чужие benchmark-числа не переносятся на KION.

| Источник | Содержательная идея | Решение для этого проекта |
| --- | --- | --- |
| Harald Steck, [Embarrassingly Shallow Autoencoders for Sparse Data, WWW 2019](https://arxiv.org/abs/1905.03375) | Регуляризованная линейная реконструкция implicit-матрицы, запрещённая диагональ, замкнутое решение через обратную Gram-матрицу. Обучаемые связи могут быть отрицательными. | Реализован EASE с проверкой формулы; его score используется отдельно, в retrieval и как признак CatBoost. Это известный алгоритм. |

Две статьи MARS имеют одинаковую аббревиатуру, но разных авторов и разные архитектуры. Обе — свежие препринты. Их результаты не подтверждают автоматически пользу temporal routing на KION.

## Наша гипотеза

Простой перебор окон меняет временную агрегацию, но оставляет связи между объектами заданными руками. EASE обучает матрицу отношений из исторического X. Для каждого cutoff считаем две матрицы B с lambda 100/1000 и три профиля пользователя: вся история, half-life 7/30 дней. Получаются шесть автоматически обученных сигналов без использования будущих targets.

Вопрос 1: может ли CatBoost использовать их как дополнительное представление и улучшить сильный ручной baseline? Это известная гибридная конструкция; вклад проекта — её строгое временное сравнение и отделение retrieval от ранжирования.

Вопрос 2: можно ли компактным gate выбирать полезную коррекцию уже обученного GBDT? Формула нашей конструкции:

`s(u,i) = z(s_GBDT(u,i)) + alpha * sum_j softmax(W c(u))_j * z(e_j(u,i))`.

Здесь z — нормализация внутри запроса с clipping, e — шесть EASE-сигналов, три retrieval-сигнала и нулевой эксперт; c — прошлые объём/давность/скорость активности и разногласие экспертов. Контекст gate общий для кандидатов пользователя. Глобальная смесь убирает зависимость от c; отдельный adaptive-вариант убирает GBDT-offset. Обучаем listwise cross-entropy на положительных запросах, с L2. Нулевой эксперт позволяет уменьшить коррекцию. GBDT-offset обучающих строк получен только на следующих по времени срезах после обучения teacher на предыдущих.

Собственная конструкция проекта — конкретная проверяемая комбинация out-of-time residual learning, temporal EASE bank и контекста надёжности для данного протокола. Приоритет общего метода не установлен: gate, residual ensemble, EASE и temporal mixtures существовали ранее. Результат фиксирует экспериментальную ценность конструкции, а не доказывает мировую алгоритмическую новизну.

## Почему не начинать с большого трансформера

В KION сохранена последняя дата пары, а не полная последовательность событий. Скрытые ранние просмотры восстановить нельзя; в 10-тысячной user-выборке истории короткие. Эти свойства ограничивают интерпретацию sequence learning. Поэтому сначала проверяем дешёвые обученные связи и анализируем разрыв retrieval/ranking. Отсутствие запуска Transformer или LightGCN не означает их проигрыш.

## Что уже проверено, а что остаётся гипотезой

Проверены EASE, degree-normalized random walk, temporal mixtures, residual correction и добавление обученных scores к CatBoost. Проба EASE с полной прошлой user-популяцией — отдельная проверка вычислимости; она получает больше данных, поэтому не входит в равноправное основное сравнение. Подробные числа и неудачные trials включены в [отчёт второго этапа](../reports/v2/REPORT.md).

Ограничения router: convex weights не создают произвольные signed residuals; небольшой контекст может плохо описывать интересы; cross-entropy не совпадает с NDCG; шкала offset влияет на обучение; эксперты коррелируют. Это возможные объяснения, а не установленные причинные эффекты. Для их разделения нужны новые заранее фиксированные абляции и ещё не открытый holdout.
