# Эксперименты

В статье оставлены основные сравнения. Здесь находятся полные результаты, включая неудачные варианты, поиск параметров и диагностические срезы.

| Каталог | Вопрос | Основной результат |
| --- | --- | --- |
| [main](main/REPORT.md), [replication](replication/REPORT.md) | Автоматический поиск временных окон, KION | Устойчивый прирост не подтверждён |
| [v2](v2/REPORT.md) | EASE-признаки и временные смеси, KION | Гибрид улучшил замороженный manual, но не подтвердил преимущество над популярностью |
| [v3](v3/REPORT.md) | Условный фон против глобального, Yambda A | Основная гипотеза не подтвердилась |
| [v3_support](v3_support/REPORT.md) | Смесь фонов с общей поддержкой | Выигрыш над manual не подтверждён |
| [v4](v4/REPORT.md) | Фон и объединение истории, Yambda B | Основная реконструкция ухудшила качество; вторичное A0 лучше G0, но слабее manual |

В каждой папке `evidence/` лежат пользовательские метрики, журнал поиска, зафиксированные настройки и контрольные суммы. Проверка без датасетов: `uv run --locked rec verify --report-dir reports/v4` (подставьте нужный каталог).

Все эти тесты открыты. Выбор новых настроек по ним потребует новой внешней проверки. Yambda A/B относятся к одному периоду; независимость по пользователям не делает B временной репликацией.
