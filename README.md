# Работа 1. Обучаемые признаки для рекомендаций

**Статья:** [article.pdf](article.pdf), 4 страницы. **Код и результаты:** [code/](code/).

Можно ли заменить часть ручных агрегатов обучаемыми представлениями без
потери качества? Работа сравнивает сильный CatBoost, EASE, контрастивные
представления и простые счётчики на KION и Yambda. Раздельно исследуются
фон искусственных переходов и способ объединения истории пользователя.

## Основной результат

- EASE-признаки улучшили ручной CatBoost на выбранном KION-срезе:
  NDCG@10 0,23173 → 0,24033. Превосходство над popularity не установлено.
- Условный фон на Yambda не подтвердил преимущество над глобальным.
- Основная реконструкция с восстановлением фона ухудшила качество.
  Вторичное арифметическое объединение улучшило свой standalone baseline,
  но осталось слабее ручного CatBoost.

В статье разделены основные и вторичные сравнения. Полный журнал включает
неудачные варианты, seed-результаты и ограничения. Победа над ручными
признаками не заявляется там, где её не подтверждают данные.

## Как проверить

Из этой папки выполните:

```powershell
cd code
uv sync --locked --extra dev --python 3.11.9
uv run --locked python scripts/verify_submission.py
uv run --locked pytest -q
```

Для проверки опубликованных чисел исходные датасеты, GPU и обучение не
нужны. Скрипт пересчитывает 6 наборов результатов, интервалы, числа статьи
и проверяет контрольные суммы комплекта. [Полное воспроизведение](code/REPRODUCE.md).

численные результаты и тесты в этом комплекте относятся к работе 1.

Все опубликованные tests открыты и не используются для нового подбора.

`uv run --locked python scripts/build_article.py` с установленным XeLaTeX.
Результат — `article-rebuilt.pdf`; файл для сдачи остаётся неизменным.
